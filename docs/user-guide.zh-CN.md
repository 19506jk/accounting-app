## 登录和界面

### 登录

1. 打开 Church Accounting。
2. 选择 **Sign in with Google**。
3. 使用管理员预先添加的 Google 邮箱登录。
4. 登录成功后，应用会打开仪表板（**Dashboard**）。

如果出现“账户尚未添加”的提示，请确认使用的 Google 邮箱与管理员添加的邮箱完全一致，然后联系管理员检查账户状态。

### 界面

- 页面左侧是主导航。编辑员和管理员都能看到日常记账功能。
- 管理员还能看到 **Administration** 区域。
- 页面右上角显示当前用户姓名和角色。
- 完成操作后，选择 **Sign out** 退出。

## 基础概念

- **会计科目表（Chart of Accounts）**：记录教会使用的所有账户，例如银行、收入、费用、负债和净资产账户。每笔交易通过这些账户说明资金从哪里来、用到哪里。
- **账户与基金（Account and Fund）**：账户表示资金的会计类别或用途，例如“银行存款”或“维修费用”；基金表示资金受到的指定或限制，例如“普通基金”或“建筑基金”。同一账户可以包含不同基金的金额，所以录入时通常两者都要选择。
- **借方与贷方（Debit and Credit）**：复式记账的两侧，不等同于日常所说的“收入”和“支出”。每笔交易的借方合计必须等于贷方合计，系统才能保持账目平衡。
- **损益表（Profit & Loss）**：显示一段期间内的收入、费用和盈余或亏损。
- **资产负债表（Balance Sheet）**：显示某一天的资产、负债和净资产。
- **总账（General Ledger）**：按账户列出每笔交易及余额变化，用于追查报表数字的来源。
- **试算平衡表（Trial Balance）**：列出所有账户的借贷余额，用来检查账簿整体是否平衡。
- **财政期间与关账（Fiscal Period and Close）**：财政期间是教会用于记账和报表的时间范围。关账会锁定已完成期间，防止后续修改影响已经审核或提交的报表。

## 开始使用前

管理员应先完成以下设置，编辑员再开始录入日常业务：

1. 在设置（**Settings**）中填写教会资料、财政年度、时区和税率。
2. 在会计科目表（**Chart of Accounts**）中检查账户和基金。
3. 在联系人（**Contacts**）中建立常用捐赠人、供应商和其他联系人。
4. 确认银行账户、默认基金和银行 CSV 文件已经准备好。

每次保存财务记录前，检查日期、金额、账户、基金、联系人及参考编号。财务期间关闭后，相关历史记录可能不能再修改。

所有金额均按管理员在 **Settings** 中配置的教会币种显示。如果货币符号与预期不符，请管理员先检查币种设置，不要通过修改金额来补偿。

## 编辑员日常操作

### 查看仪表板

打开 **Dashboard** 查看总收入、总支出、净盈余、银行余额和最近交易。仪表板用于快速了解当前情况；正式核对数字时，应使用报表（**Reports**）。

### 管理账户和基金

打开 **Chart of Accounts**：

- 选择 **+ Add Account** 新增账户，填写代码、名称和类型后保存。
- 选择现有账户进行编辑。
- 选择 **+ Add Fund** 新增基金，或编辑现有基金。
- 使用 **Show Inactive** 查看已停用项目。
- 选择账户可查看账户明细，并可导出 Excel。

编辑员可以新增、编辑和停用项目，但只有管理员可以执行删除操作。不要为了临时分类随意新增账户；先确认现有账户或基金能否满足需要。

### 管理联系人

打开 **Contacts**：

1. 选择新增联系人。
2. 选择类型和类别，并填写显示名称。
3. 捐赠人应填写可识别的捐赠人编号、姓名和地址；供应商应填写付款所需资料。
4. 保存后，可再次打开记录进行编辑或停用。
5. 使用 **Show Inactive** 查看和恢复已停用的联系人。

只有管理员可以永久删除联系人。已用于交易的联系人通常应停用，而不是删除。

### 处理账单

打开 **Bills**：

1. 选择 **+ New Bill**。
2. 选择供应商，填写账单日期、到期日、账单编号和费用明细。
3. 检查费用账户、基金、金额及税率，然后保存。
4. 在账单列表中使用状态和供应商筛选器查找账单。
5. 打开账单后，可编辑、应用抵扣（用供应商信用额减少欠款）或选择付款。

编辑员可以新增、编辑和支付账单，但只有管理员可以作废（**Void**）账单。

### 录入和查看普通交易

打开 **Transactions**：

- 使用类型和账户筛选器查找交易。
- 选择 **+ New Transaction** 新增日记账。
- 填写日期、说明和参考编号。
- 为每一行选择账户和基金，并填写借方或贷方金额。
- 借贷合计及各基金必须平衡后才能保存。
- 可编辑未受关闭期间限制的现有交易，也可保存和复用交易模板。

只有管理员可以删除交易。发现错误时，不要另录一笔来掩盖问题；应先确认原交易是否可编辑，并在需要删除或处理关闭期间记录时联系管理员。

### 录入存款

打开 **Make a Deposit**：

1. 填写日期、存入的银行账户、参考编号、存款总额和说明。
2. 为每一行选择收入账户、基金、捐赠人及付款方式，并填写金额。
3. 如需增加明细，选择 **+ Add Line**。
4. 匿名捐款可使用 **Allocate Anonymous** 进行分配。
5. 确认明细合计等于存款总额后提交。

系统不会允许不平衡的存款保存。提交前应将存款单或银行记录与录入金额核对。

### 录入支出

打开 **Record Expense**：

1. 填写日期、参考编号、收款人（Payee）、付款账户、基金、总金额和说明。
2. 添加费用明细，并为每行选择账户和填写金额。
3. 确认表单平衡后提交。

可将经常重复的支出保存为模板。模板只减少重复输入，使用时仍需核对日期、金额和收款人。

### 导入和匹配银行流水

打开 **Bank Feed Queue**。推荐按以下顺序处理：

1. **Import**：选择银行账户和基金，上传 CSV，检查预览，然后选择 **Confirm Import**。
2. **Review Queue**：比较新流水与冲突流水，选择 **Mark Duplicate** 或 **Confirm New**。
3. **Match**：查找对应日记账，确认候选匹配；无对应记录时可创建新日记账、支付匹配账单、暂缓或忽略。
4. **Rules**：建立或编辑自动匹配规则，并在使用前确认条件和目标账户。

重复导入的行可能被跳过或送入审核队列。不要只根据金额确认匹配，还要核对日期、说明、参考编号和收付款对象。编辑员不能删除匹配规则，需要删除时请联系管理员。

### 银行对账

打开 **Reconciliation**：

1. 选择 **+ New Reconciliation**。
2. 选择银行账户，填写对账单日期和期末余额。
3. 打开对账记录，逐笔勾选已在银行对账单出现的存款和付款。
4. 使用全选或按类型选择功能时，仍应人工检查所选范围。
5. 确认差额为零后，请管理员执行关闭。

编辑员可以建立、编辑对账和勾选明细；只有管理员可以关闭、重开或删除对账。

### 查看和导出报表

打开 **Reports**，选择报表类型：

- 损益表（**Profit & Loss**）
- 资产负债表（**Balance Sheet**）
- 总账（**General Ledger**）
- 试算平衡表（**Trial Balance**）
- 按捐赠人收入汇总（**Income by Donor — Summary**）
- 按捐赠人收入明细（**Income by Donor — Detail**）

选择日期或截止日期，并按需要选择基金、账户、收入账户或捐赠人，然后选择 **Run Report**。生成后可使用 **Export Excel** 导出当前报表，或使用 **Export Financial Report** 导出财务报表组合。

如果报表数字异常，先核对筛选条件，再通过总账追查相关账户和交易。财政年度硬关账（**Hard Close Fiscal Year**）只能由管理员执行。

## 管理员操作

以下功能位于左侧 **Administration** 区域。高风险操作应在确认已获得授权并完成必要备份或复核后进行。

### 管理用户

打开 **Users**：

1. 选择 **+ Add User**。
2. 输入用户的 Google 邮箱并分配角色。
3. 保存后，用户可用该邮箱首次登录。
4. 在列表中可调整其他用户的角色，或使用 **Deactivate** 和 **Activate** 控制访问。
5. 对尚未完成首次登录的邀请，可选择 **Cancel** 取消。

管理员不能在此页面修改自己的角色或停用自己。分配 Admin 前应确认对方确实需要用户管理、系统设置和删除权限。

### 编制预算

打开 **Budget Planning**，选择财政年度，为收入和费用账户填写预算金额。离开输入框后系统会保存变更。使用汇总和上年比较检查收入、费用及净额，完成后可导出预算。

### 生成捐款收据

打开 **Donation Receipts**：

1. 选择财政年度和应计入收据的收入账户。
2. 检查教会 CRA 信息、捐赠人姓名和地址。
3. 如需修改收据格式，编辑并保存 HTML 模板。
4. 先预览收据，再执行批量生成。

正式生成前应确认金额、捐赠人资料、签名和注册号。模板中的 HTML 会直接影响收据内容，修改后必须预览。

### 查看审计日志

打开 **Audit Log**：

- 在变更日志和访问日志之间切换。
- 按操作人、实体类型、动作和结果筛选。
- 使用日志调查记录由谁、何时执行了什么操作。

审计日志用于追踪，不用于直接修改财务记录。

### 配置系统

打开 **Settings** 管理：

- 教会名称、地址、电话和邮箱。
- CRA 慈善注册号。
- 财政年度起始月份、币种和教会时区。
- 关闭的财政期间及最近期间的重开。
- 银行导入默认抵销账户（导入存款时用于自动填入交易另一侧的账户）。
- 分会会计和财务主管姓名及签名。
- 账单使用的税率及其启用状态。

这些设置会影响收据、报表、日期边界、导入和账单计算。修改前记录原值，并在修改后检查相关输出。

### 管理高风险操作

管理员还可以：

- 删除或停用账户、基金和联系人。
- 删除交易、作废账单和删除银行匹配规则。
- 关闭、重开或删除银行对账。
- 对财政年度执行硬关账，或重开最近关闭的财政期间。

执行前应确认目标记录、财政期间、影响范围和授权。已用于其他记录的基础资料优先停用，不要删除。关账前应完成银行对账、检查试算平衡表和财务报表，并处理所有异常；关账后如需修改历史数据，应由管理员按组织流程重开期间。

## 常见问题

### 无法登录

- 确认使用管理员添加的 Google 邮箱。
- 如果浏览器阻止登录弹窗，请允许本站弹窗后重试。
- 若账户已停用或尚未添加，请联系管理员。

### 看不到 Administration 菜单

只有 Admin 角色能看到该菜单。编辑员如需执行管理员操作，应联系管理员，不要通过直接输入页面地址绕过权限。

### 保存时提示权限不足

当前角色不允许执行该操作，或该操作仅限管理员。保存其他编辑内容，并将所需操作及目标记录告知管理员。

### 交易无法保存

检查必填字段、借贷合计、基金平衡、金额格式，以及交易日期是否位于已关闭期间。

### 报表没有数据或数字不符合预期

检查日期范围、截止日期、基金、账户、捐赠人和收入账户筛选条件。清除不必要的筛选后重新运行，再使用总账追查具体交易。

### 银行 CSV 无法导入

确认已选择银行账户和基金，文件是受支持的 CSV，且至少解析出一行。根据页面显示的错误和警告修正文件；不要反复导入同一文件来尝试绕过错误。

### 发现关闭期间的错误

不要使用当前日期创建不明的抵销交易。记录错误详情，并联系管理员判断应重开期间，还是在当前期间录入经过授权的调整分录（用于更正已入账错误的会计记录）。
